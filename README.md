# Приложение для анализа банковских транзакций

## Описание:

Виджет банковских операций клиента - это веб-приложение на Python для управления банковскими операциями.

## Цель проекта:

Создать приложение для работы с банковскими операциями

## Установка:

Клонируйте репозиторий:

```
git clone https://github.com/username/project-x.git
```

Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Пример работы с функциями:

1. Функция `home_page` создана для главной страницы, она принимает на вход строку с датой и временем в формате 
   YYYY-MM-DD HH:MM:SS, а возвращает JSON-ответ
2. Функция `create_error_response` генерирует json-ответ с ошибкой
3. Функция `create_success_response` генерирует json-ответ с успешными данными
4. Функция `load_user_settings` згружает настройки из файла user_settings.json
5. Функция `load_excel_data` загружает данные из Excel-файла my_operations.xlsx
6. Функция `filter_data_by_date_range` фильтрует данные по диапазону дат
7. Функция `get_currency_data` получает данные о курсах валют за указанный диапазон дат
8. Функция `get_stock_data` получает данные о ценах на акции за указанный диапазон дат
9. Функция `convert_date_string` преобразует строку даты в объект datetime
10. Функция `get_month_start_date` возвращает дату начала месяца для заданной даты
11. Функция `simple_search` принимает строку в формате списка словарей и возвращает json-ответ
12. Функция `spending_by_category` принимает на вход DataFrame с транзакциями, название категории и дату, 
    а возвращает json-ответ с тратами
## Тестирование

Для тестирования функционала используется фреймворк pytest. Тесты находятся в директории tests и покрывают основные
функции проекта.

Для запуска тестов выполните команду:

```
pytest
```

8. **Тестирование** `test_load_user_settings_error`: тест для обработки ошибки user_settings.json
9. **Тестирование** `test_filter_data_by_date_range`: тест для фильтра данных по диапазону дат
10. **Тестирование** `test_get_currency_data`: тест для данных о курсах валют

12. **Тестирование** `test_get_stock_data`: тест для данных о ценах на акции
